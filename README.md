# 🚀 AI Sales Copilot - Atendimento em Loja

![Category](https://img.shields.io/badge/Domain-AI%20Sales-orange)

Repositório focado em **Engenharia de Prompt** para suporte comercial. Este projeto estrutura uma IA capaz de gerar argumentos persuasivos e contornar objeções em tempo real para vendedores de loja física.

## 📁 Estrutura de Arquivos

*   📄 [**prompt-sistema.txt**](./prompt-sistema.txt) - Instruções de Persona e Regras de Negócio.
*   📝 [**exemplo-pedido.md**](./exemplo-pedido.md) - Formato de entrada dos dados do cliente.
*   ✅ [**resposta-esperada.md**](./resposta-esperada.md) - Exemplo de saída otimizada para conversão.

## ⚙️ Como Funciona (Lógica)

1.  **Input:** O vendedor insere o produto e o perfil do cliente.
2.  **Processamento:** A IA aplica o framework **AIDA** e a técnica **Feel-Felt-Found**.
3.  **Output:** O sistema entrega um roteiro de 30 segundos para o vendedor utilizar imediatamente.

## 🛠️ Tecnologias Utilizadas

- **Prompt Engineering** (Reasoning & Persona Pattern)
- **Sales Frameworks** (Spin Selling & Neurovendas)
- **Markdown/JSON** para estruturação de dados.
